# D-07 — The first screen and the four-beat onboarding

Status: open (blocked by D-06, D-09). Kind: decision.

## Question

What does a newcomer see and do in the first 60 seconds, and what does the title actually show?

## Options

1. **One title, four beats inline** (recommended): the title's primary "Chơi" starts the first
   run; the onboarding is four contextual beats (fire one, merge one, fill the gauge to the shake,
   ship one) inside the first Orders run, each one action + a short line; the machine points at the
   loader; the how-to stays as the reference; the first order is the fourth beat's payoff. No
   modal wall.
2. **A separate tutorial mode**: a scripted 2-minute level, then the title/modes. More controlled;
   a second thing to maintain; the child may skip it.
3. **A "Cách chơi" card only** (today): three hints; cheap; the pressure/shake/ship are still new
   mechanics a newcomer meets by accident.
4. **A guided first Orders run with a coach**: the same as 1 but the coach is the mascot with
   lines/animations. The warmest; more content; D-10.

## Recommendation

1, with the mascot's one-line coach as the 2.3 polish (4). The four beats are **inside** the first
Orders run (not a separate tutorial): the first order is "Xuất một khối 16", so the beats lead to a
real win. The title: the brand mark + wordmark, the primary "Chơi"/"Chơi tiếp", the mode cards, the
daily, the workshop, the leaderboard, the settings, the how-to, "Về Tò He"; the "Cách chơi" always
available. The four beats have a skip and can be replayed; the child can meet them again; a return
player sees no onboarding.

## Cost and risks

The contextual coach (the hand/aim/ring/labels), the first order, the title layout, the skip/seen
state, the tests. The risk is a wall of hints or an over-scripted first run; the beats are one
action each, and the run stays playable.

## What would change my mind

- The player is confused after the four beats: add a fifth (the first part/choice) or a short
  "Cách chơi" recap at the ticket.
- The first Orders order is too high for the fourth beat: make the first order 8/16, and the
  pressure/shake beat earlier.
