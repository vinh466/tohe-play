## Package rules

| Package | May depend on | Must not |
| --- | --- | --- |
| `@tohe/contract` | `zod` | anything in this repo |
| `@tohe/game-sdk` (game side) | types from `@tohe/contract` only | runtime dependencies of any kind |
| `@tohe/game-sdk/host` | `@tohe/contract` | — |
| `@tohe/game-kit` | `@tohe/game-sdk` (types), Phaser (optional peer, `./phaser` entry only) | the hub, the API |
| `games/*` | `@tohe/game-sdk`, `@tohe/game-kit`, any library that fits the game | the hub, the API, other games, network access |
| `apps/hub` | contract, SDK host, generated API types | game code |
| `services/api` | NuGet packages in `Directory.Packages.props` | game code |

TypeScript packages inside the monorepo export their **source** (`"exports": "./src/index.ts"`); bundlers and
Node 24 (type stripping) consume it directly, so there is no build step between packages. The SDK additionally
builds `dist/tohe-game-sdk.iife.js` for games without a bundler.

## Generated, committed files

| File | Generated by | Checked by |
| --- | --- | --- |
| `packages/contract/schema/*.json` | `pnpm --filter @tohe/contract build` | CI fails on drift |
| `services/api/openapi/tohe-api.json` | `dotnet build` (build-time OpenAPI) | CI fails on drift |
| `apps/hub/src/api/schema.gen.ts` | `pnpm --filter @tohe/hub generate:api` | CI fails on drift |
| `apps/hub/public/*.png` | `pnpm --filter @tohe/hub generate:icons` | — |
| `services/api/src/Tohe.Api/Infrastructure/Database/Migrations/*` | `dotnet ef migrations add <Name>` | tests apply them to a real PostgreSQL |
